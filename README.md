# Atakan Özdal

**Yazılım Geliştirici, atomiXbilişim**

İşletmelerin günlük operasyonlarını yöneten web tabanlı yazılımlar ve mobil uygulamalar geliştiriyorum. Çalışmalarım; teknik servis, randevu, kiralama, satış noktası ve mühendislik süreçlerinin dijitalleştirilmesini kapsıyor. Analiz, geliştirme, yayına alma ve sonrasındaki bakım süreçlerini uçtan uca yürütüyorum.

Türkiye ve İsviçre'de farklı ölçeklerdeki işletmelerle proje bazlı çalıştım.

Geliştirdiğim ürünlerin büyük bölümü ticari lisansla sunulduğu için kaynak kodları özel depolarda tutulmaktadır. Aşağıda ürünlerin kapsamı ve kullanım durumu yer almaktadır.
